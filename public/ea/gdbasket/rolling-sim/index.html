AGILE Rolling + ถอนเงิน

ข้อมูลจริง: ทุกตะกร้าของ AGILE M15 2018-01 → 2026-11-13 (2018–2025 = GOLD#.xm · 2026 = GOLD# · รันที่ cap 1000 คงที่) เอามาคิดใหม่ตามขนาด cap ของแต่ละแบบ · จุดเทา = รัน MT5 จริงที่เปิด rolling (dev 0.19 · โชว์เมื่อตั้งเริ่ม 2018 ทุน 2000 cap 1000)

เงินในบัญชี
เงินที่ถอนออกมาแล้ว (สะสม)
คิดยังไง
  • ตะกร้าทุกใบ + ลอยต่ำสุดของแต่ละใบ มาจาก CSV จริง (รัน cap 1000) → กำไร/ขาดทุน/ลอย คูณ cap ÷ 1000 ของ cap ที่ใช้อยู่ตอนตะกร้านั้นวิ่ง
  • เริ่มวันไหนก็ได้: เริ่มจากตะกร้าแรกที่ปิดในวันนั้น แล้วนับรอบใหม่เอง (สำเร็จ = กำไรครบ +1 cap · SO = ตะกร้าที่โดน SO ใน backtest) — เริ่มกลางรอบเดิม ลำดับตะกร้าของจริงอาจไม่เหมือนเป๊ะ
  • · ขยับ cap กลางรอบ (ทุกวัน / ทุกวีค / ทุกเดือน / ทุก X%) ทำตอนไม่มีตะกร้าเปิด แต่ยังใช้จังหวะจบรอบเดิม = ประมาณการ EA จริงยังทำแบบนี้ไม่ได้ (โค้ดตอนนี้ขยับตอนจบรอบอย่างเดียว)
  • กฎที่เคาะไว้ (live): cap = บัญชี × สัดส่วน ไม่ต่ำกว่า cap แรก ไม่เกินเพดาน · โดน SO = ลด cap ตอนจบรอบทุกแบบ · ถอนกลางรอบ = ลด cap ทันที (ไม่เพิ่ม) · บัญชี < cap = ไม่เปิดตะกร้าใหม่ (เส้นหยุด)
  • แกนเงิน log = ทุกเส้นตารางเพิ่มทีละเท่าตัว (1k 3k 10k 30k…) ช่วงต้นเงินน้อยยังเห็นการขึ้นลง · ปกติ = เส้นตารางห่างเท่ากัน ช่วงหลักพันจะแบนติดพื้น
  • ถอนได้สูงสุดให้บัญชีเหลือ 2 × cap แรก — ส่วนที่ขอเกินนับเป็น "ถอนไม่ได้เต็ม"
  • รวมได้ทั้งหมด = เงินในบัญชีตอนจบ + เงินที่ถอนออกมาแล้ว · รอบสำเร็จ / SO = จำนวนรอบที่ได้ +cap / จำนวนรอบที่โดน SO · cap ตอนจบ = ทุนที่ใช้คิดไม้ของรอบสุดท้าย
  • DD = ยอดบัญชีสูงสุดที่เคยขึ้นไป (หักเงินที่ถอนออกไปแล้ว) เทียบกับ equity ต่ำสุดหลังจากนั้น (บัญชี + ลอย) — รวมทั้งเงินที่เสียจาก SO และลอยของตะกร้าถัดไป · เลขข้างหลังคือยอดสูงสุด → จุดต่ำสุด
  • ลอยรอบ % ของ cap = ลอยของตะกร้าเทียบ cap ของรอบ ไม่นับตะกร้าที่โดน SO ไม่ขึ้นกับแบบทบ · ลอย % ของบัญชี = ลอยเทียบเงินทั้งบัญชีตอนนั้น · ชี้เมาส์ที่แต่ละแถวในการ์ดเพื่อดูคำอธิบาย
  • จุดเทา MT5 จริงเลขไม่ตรงเส้น "ทุกรอบ" เป๊ะ เพราะรันจริงใช้ cap ใหญ่ขึ้นแล้วจังหวะรอบเปลี่ยน (ตั้งแต่รอบ 4) — ไว้ดูว่าเส้นจำลองอยู่ระดับเดียวกับของจริงไหม
